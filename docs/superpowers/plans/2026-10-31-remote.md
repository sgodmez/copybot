# SFTP, FTP et S3 — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** masquage complet des secrets dans le moteur, API de confirmation, plugin `copybot-plugin-remote` avec
SFTP, FTP/FTPS et S3 en entrée et en sortie.

**Architecture:** une abstraction `RemoteFs` interne au plugin, une lecture et une écriture génériques au-dessus,
trois implémentations (JSch, Commons Net, S3 SigV4 maison).

**Spec:** `docs/superpowers/specs/2026-10-31-remote-design.md` (contraignante).

## Global Constraints

- JDK 25 ; `mvn -q verify -pl <module> -am` ; `mvn -q verify` à la racine en fin de plan.
- API 1.2 non publiée : ajouts seulement, empreinte régénérée (`-Dplugin.api.update=force`), diff = lignes ajoutées.
- Plugin : gabarit des autres (`plugin.code`, 1.0.0, assembly en dernier, module-info, `catalog.json` en/fr/it,
  bundles en/fr/it + `PluginBundleTest`), ajouté à `copybot-plugin/pom.xml`. Dépendances d'exécution : JSch (mwiede)
  et commons-net seulement (modules automatiques acceptés, comme gps-zone) ; aucune dépendance sur un module JDK
  absent de l'image jlink (vérifier les `requires` des jars). Serveurs de test en portée test seulement.
- Aucun secret (mot de passe, phrase de passe, clé secrète, signature) dans un journal, un message ou `toString`.
- Aucun accès réseau externe dans les tests.
- Un commit par tâche, message en anglais, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Les 11 chemins du §1 masqués, exceptions de contrôle intactes.
2. Confirmation : jamais de blocage sans fin (annulation → non), CLI « oui » + avertissement, échantillon « non ».
3. Empreinte SFTP : inconnue → question, changée → refus sans question, `known_hosts` écrit de façon sûre.
4. Écriture distante : temporaire + renommage, conflits, vérification de taille, rien de partiel en cas d'échec ou
   d'annulation (temporaire supprimé, multipart abandonné), source jamais supprimée si conservée.
5. Connexions : réservoir borné, tout fermé dans `afterAll`, pas de fuite sur erreur.
